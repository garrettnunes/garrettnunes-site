        02 — The work
        
What runs underneath

        

          All three companies are operated through one body of software I build and run
          myself: an agentic operating system, a set of small apps, and a running list of
          projects. None of it is a demo. Each piece carries a real part of the businesses.
        

      


      

        

          
The operating system

          

            .seed is an agentic OS built on Claude Code. Every capability is a
            word: a skill with a mechanical half that actually runs, so the model plans
            and code executes. Every word declares what it can break — read ·
            write · spend · send · irreversible — and the system enforces that ladder
            before anything runs. Nothing sends on its own. Software drafts; a person sends.
          

          

            It reads the companies’ ledgers, mail and sites, runs the routines that need no
            brain as plain code, remembers one fact per file, and asks when a decision is mine.
          

        

        

          
“Every word has a core like a peach. The seed is the mechanical code. As the
          mechanical code grows, so can the potential of the idea.”

          — the idea the whole system is built on

        03 — Approach
        
How I build

        

          The same principles show up in everything — whether it’s an AI
          agent, a parts catalog or a lease.
        

      


      

        

          01
          
Automate the boring parts first

          
The highest-leverage software replaces the work nobody wants to do twice. Find the repetition, encode it, move on.

        

        

          02
          
Systems over heroics

          
A process that runs without me is worth more than a great day of manual effort. Build the machine, then improve the machine.

        

        

          03
          
Ship, measure, refine

          
Real data beats opinions. Get something live, watch how it behaves, and let the metrics decide what gets built next.

        

        

          04
          
Lean by design

          
Small teams, sharp tools, and software that does the heavy lifting. Stay fast by staying simple.

        

        

          05
          
Nothing sends on its own

          
Every action is graded by what it can break. Reads are free, writes stay inside the workspace, spending asks, and a message leaves only when a person presses send.

        

        

          06
          
Files are truth

          
If it is not in a file it did not happen. Every dashboard is a view, every claim names its source, and a number comes with the time it was measured.

        

      

    


    
    

      

        

          04 — About
          
Hi, I’m Garrett.

          

            I’m a founder and builder based in Maryville, Tennessee. I run
            three companies: Factory Parts, the wheel business behind
            OEMWheel.com; Fazer Tech, my technology company; and
            Huts Business Park, where the other two are tenants.
          

          

            I’ve been programming since I was a kid. Today my work spans applied AI and
            agent systems on one side and e-commerce and property operations on the other. The
            thread connecting them is automation: I’d rather build a system once than do
            the same task a hundred times. Lately that means autonomous tooling that handles
            real operational load — not demos, but software that has to actually work.
          

          

            I’m biased toward shipping. A rough system running in the real world
            teaches me more in a week than a perfect plan teaches me in a month, so I
            get things live early and let what actually happens decide the next move.
            The companies I run are, in a real sense, a testbed for that idea —
            each one a place to prove that software can carry more of the load than
            people assume.
          

          

            If you run a business nearby and want the boring parts handled, or you’re
            working on hard problems in AI, automation or commerce and want to compare notes,
            I’d like to hear from you.
